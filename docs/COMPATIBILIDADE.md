# Compatibilidade

## Matriz declarada

| Componente | Versão |
| --- | --- |
| WHMCS | 9.0.5 ou superior da linha 9.x |
| PHP | 8.3, 8.4 e 8.5 |
| Banco | MySQL ou MariaDB suportado pelo WHMCS |
| Tema administrativo | Blend |

## Dependências

O módulo utiliza o Capsule já carregado pelo WHMCS e não exige Composer, bibliotecas externas ou conexão com serviços de terceiros.

## Limites de compatibilidade

A declaração acima não substitui homologação. Customizações de schema, hooks de terceiros e módulos que alterem preços podem modificar o resultado esperado.
