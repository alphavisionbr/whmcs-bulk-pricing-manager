# Suporte

Antes de abrir uma solicitação, confirme que está utilizando uma versão publicada do Alphavision® WHMCS Bulk Pricing Manager e consulte a documentação disponível no repositório.

## Informações necessárias

Ao solicitar suporte, informe:

- versão do WHMCS;
- versão do PHP;
- versão do módulo;
- tipo de entidade afetada;
- ID do lote, quando existir;
- mensagem exibida no painel;
- trecho correspondente do Module Log, sem dados sensíveis.

Nunca publique senhas, tokens, chaves privadas, dados pessoais ou informações confidenciais de clientes.

## Issues

Utilize Issues públicas para bugs reproduzíveis, propostas de melhoria e dúvidas que possam ser discutidas publicamente.

Para vulnerabilidades de segurança, consulte [SECURITY.md](SECURITY.md).
